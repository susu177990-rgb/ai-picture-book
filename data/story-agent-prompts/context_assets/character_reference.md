# Reference: 角色物理解剖与材质锚点库 (Physical & Anatomical Anchors)

## 0. 角色库调用协议 (Asset Execution Protocol)
- **隐式运算原则**：本文件中的所有设定，Agent 仅在后台作为“物理引擎”进行推演运算。在输出任何剧本或分镜时，**绝对禁止**直接复述角色的基础外观设定（如毛发颜色、服装款式）。
- **动态转化原则**：当剧情发生变化时，Agent 必须强制读取此处的【解剖结构】与【服装材质】，将其转化为对应的“微表情”、“空间张力”和“逻辑性战损”。
- **格式示例隔离**：`examples/character_reference_format_examples.md` 中存有多维度片段示例，**仅供理解各字段的填写格式与颗粒度**。禁止在用户未指定时套用或组合其中任何角色设定。Agent 应据此学习「如何填」，而非「填谁」。
